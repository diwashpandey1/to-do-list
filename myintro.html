ABOUT THIS PROJECT

A small tool for everyday tasks.

Daylist began as a learning project by Diwash Pandey, built with the basics of the web.

The idea is intentionally simple: make it easy to add tasks, mark them done, and find the ones that need attention. There are no accounts or services behind it—your list is kept in your browser.
